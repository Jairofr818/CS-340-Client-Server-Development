# CS-340-Client-Server-Development
In this class, I have learned how to build programs that are maintainable, readable and flexible through modular separation of application components, good names and documentation of the functions. For example, in Project One, I developed a CRUD module in Python that contained the functionality to connect the MongoDB database as well as perform create, read, update and delete operations. Then, I used that same module in Project Two for connecting the dashboard widgets to the aac.animals collection. Thus, I managed to separate the database operations from the dashboard structure and functions in order to improve the program's understanding, testing and modifications. Moreover, in the future, the CRUD module can be reused in other dashboards, websites, reporting applications and animal management software that will use the same database.

For the development of the Grazioso Salvare application, I first examined the requirements provided by the customer, then split the task into subtasks and converted the request for the rescue categories into MongoDB queries by the criteria of breeds, sex and age of animals. After that, I built the interactive data table, filters for rescue, pie chart and geolocation map, and performed testing to assure that all of them update simultaneously. This project differs from my previous assignments in the way that this time I had to merge database management, Python programming, authentication, data visualization and dashboard building within one application. These are the skills used by computer scientists when designing the system for organizing information and automating processes, helping people to make decisions based on this information. The Grazioso Salvare dashboard can increase the efficiency of employees in filtering of the shelter records and finding potential candidates for rescue training among them.
